### 俄罗斯方块游戏 Bug 修复

**时间**: 2026-05-19 17:00

**问题**: 玩家反映游戏中途方块突然消失

**根本原因**:
1. `gameLoop` 在 `spawn()` 失败时直接 return，但 `gameState` 仍为 'playing'
2. 渲染条件 `gameState === 'playing'` 阻止画面更新
3. `lock()` 后 `current` 被设为 null，在 `spawn()` 成功前玩家看不到方块
4. 缺少自动恢复机制

**修复内容**:
1. **渲染循环保护** - 始终渲染游戏画面（包括暂停和游戏结束时）
2. **自动生成保护** - 当 `current` 为 null 时自动调用 `spawn()`
3. **spawn 失败保护** - 确保 spawn 失败后调用 `gameOver()`
4. **消行卡死检测** - 添加 `_clearStartTime` 超时机制，1秒未恢复自动修复
5. **等待视觉效果** - current 为 null 时显示 ⬇️ 图标
6. **详细日志** - 添加 console.log 便于调试

**问题**: 游戏玩一段时间后出现卡顿

**修复内容**:

1. **gameLoop逻辑修复**
   - 添加 `if(!this.current) return;` 防止方块为空时继续下落
   - 确保消行动画期间（isClearing）不执行下落

2. **startDrop定时器修复**
   - 开始前清理旧定时器 `clearInterval(this.dropTimer)`
   - 设置 `this.dropTimer = null` 防止残留
   - 仅AI模式（VS对战）使用定时器，玩家模式由requestAnimationFrame驱动

3. **VS模式双重下落修复**
   - 移除gameLoop中对 `vsGame.gameLoop(ts)` 的调用
   - 对手仅通过独立的setInterval驱动，避免双倍速度

4. **gameOver防重复调用**
   - 添加 `if(this.gameState === 'over') return;` 防止多次触发

5. **粒子系统内存限制**
   - 添加 `if(this.particles.length > 500)` 限制粒子总数

6. **BOSS攻击间隔优化**
   - 最小间隔从3000ms增加到5000ms
   - 攻击伤害从 `level/4` 调整为 `level/5`，降低难度

7. **VS模式对手清理**
   - 对手HP归零时立即清理定时器
   - 分离对手游戏中和已结束的处理逻辑
