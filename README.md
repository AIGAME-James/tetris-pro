# TETRIS PRO

一款功能丰富的俄罗斯方块游戏，支持多种游戏模式。

## 🎮 游戏模式

- **经典模式** - 传统俄罗斯方块体验
- **计时模式** - 90秒内获得最高分
- **竞速模式** - 自选时间，消除指定行数获胜
- **Boss模式** - 对抗会自动攻击的Boss
- **AI对战** - 与智能AI同屏对战

## 🌟 功能特性

- 7种难度等级
- 多种方块主题
- 粒子特效
- 星空背景
- 分数排行榜
- 键盘/触摸控制

## 🚀 部署到 GitHub Pages

### 方法一：自动部署（推荐）

1. 进入仓库 Settings → Pages
2. Source 选择 "Deploy from a branch"
3. Branch 选择 `master`，文件夹选 `/ (root)`
4. 点击 Save
5. 等待1-2分钟，访问 `https://aigame-james.github.io/tetris-pro/`

### 方法二：使用 Actions 自动部署

仓库已配置自动部署，每次推送到 master 分支会自动更新 GitHub Pages。
